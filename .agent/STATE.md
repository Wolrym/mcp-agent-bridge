# STATE: ремейк MCP-моста

Оновлено: 2026-11-04. Фаза: 0 (аналіз + питання користувачу).

## Проєкт

Два локальні MCP-сервери (Files System :9500, Terminal :9501), PySide6-панель і
Cloudflare Tunnel. Через них ШІ-агенти (зараз Notion AI) працюють з файлами і
терміналом на ПК користувача. Windows, shell = cmd.exe. Деталі: ARCHITECTURE.md.

## Задача користувача

1. Проаналізувати проєкт і наявні MCP-інструменти.
2. Розумно покращити інструменти без зайвих тулів: wait_process, передача
   файлів/зображень/PDF, інформативні логи викликів.
3. Баги, швидкість, безпека (ніхто сторонній не має керувати ПК).
4. Прибрати згадки Notion: продукт стане загальним MCP для агентів.
5. Іконка; запуск без консолі без збірки, але логи мають лишатися видимими.
6. Скіл mcp-coding-agent сильно не міняти. Зробити 2 копії:
   a) оновлена під нові інструменти;
   b) `-brief`: те саме + пам'ять між сесіями (часті коміти, теги на стабільних
      станах, STATE-файл, збереження промптів, відновлення після обриву чату
      "Interrupted"), робота в папці, яку дав користувач; вихід за неї лише з
      дозволу.
7. Редизайн GUI: не чисто чорний, єдиний стиль, нормальна розкладка, без
   AI-слопу. Робити В КІНЦІ, окремим тегом.

## Жорсткі заборони

- НЕ перезапускати і не зупиняти MCP-сервери (run_core.py, python-процес
  панелі) і cloudflared: агент працює через них же.
- НЕ чіпати auth/token у config/settings.json.
- Завжди абсолютні шляхи; у run_command/start_process завжди cwd.
